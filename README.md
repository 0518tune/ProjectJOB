# 🏡 ProjectJOB — 인생 시뮬레이션

> ▶ **플레이: https://projectjob-psi.vercel.app**
> 📑 기획서: `02_ProjectJOB_프로토타입_기획서.html` (브라우저로 열기 · Ctrl+P로 19p PDF 내보내기)

20개 직업의 하루를 시나리오로 체험하고, 성향 분석·마이룸 꾸미기·앨범 수집까지 즐기는
브라우저 기반 라이프 시뮬레이션 게임입니다. 순수 정적 HTML/CSS/JS로 만들어져 별도 서버나 빌드 없이
`index.html`만 열면 바로 실행됩니다.

**기획 의도** — 많은 사람이 자신이 무엇을 좋아하고 잘하는지 모른 채, 이름·연봉·명예만 보고 진로를 정합니다.
직업은 수없이 많지만 하루라도 겪어 볼 기회는 거의 없고, 진로 교육은 재미가 없어 시작조차 하지 않습니다.
게임으로 다가가면 흥미가 먼저 생기고 자기 이해가 뒤따라온다는 가정에서 출발했습니다.
프로 취준생 모드에는 자격증·경쟁률·전망·연봉·면접 팁까지 담아, 어릴 때부터 진로를 재미있고 의미 있게
알아보는 시간을 갖게 하는 것이 목표입니다.

## 🎬 인게임 연출 시퀀스 시스템 (기획 핵심)

퀘스트 한 컷의 **카메라 워크와 캐릭터 동선**을 코드가 아니라 **데이터(큐시트)** 로 기술합니다.

```js
// js/direction.js — DIRECTION_PRESETS
긴장_클로즈업: {
  이름: '긴장 · 상대 클로즈업', 태그: ['긴장', '딜레마'],
  의도: '상대의 한마디가 상황을 조이는 순간. 얼굴로 붙어 도망갈 공간을 없앤다.',
  큐시트: [
    { t: 0.0,  샷: '타이트투샷', 전환: 0.5, 이징: 'easeOut' },
    { t: 0.35, 배우: 'npc', 마크: '좌측앞', 회전: -38, 전환: 0.8, 걷기: true },
    { t: 0.6,  샷: '클로즈업_상대', 전환: 1.0, 이징: 'easeInOut' },
    { t: 1.4,  배우: 'npc', 모션: '고민' },
  ],
},
```

- **CAMERA_SHOTS** — 샷(카메라 위치·피사체·화각) 정의 테이블. 실제 무대 비율에서 한 샷씩
  렌더해 헤드룸을 맞춘 값입니다.
- **ACTOR_MARKS** — 무대 스탠딩 마크 테이블. 동선은 좌표 대신 마크 이름(`좌측앞`)으로 지시하므로
  무대 크기가 바뀌어도 큐시트를 고칠 필요가 없습니다.
- **DIRECTION_PRESETS** — 연출 프리셋 11종. `이름/의도/태그` 메타가 곧 기획 문서입니다.
- **Director** — 큐시트를 3D 무대에 재생하는 런타임(트윈·셰이크·감정 모션).
- **DirectionPicker** — `연출` 지정이 없는 컷은 컷 위치(도입/중반/마지막)와 선택지 점수의 톤을 읽어
  프리셋을 자동 배정합니다. 기획자는 "여기는 꼭 이 그림"인 컷만 지정하면 됩니다.

기획자는 `index.html`의 기획자 데이터 존에서 시나리오 행에 한 칸만 채우면 됩니다.

```js
{ 단계:3, 연출:'당황_흔들림', 상황:'저녁 뉴스에 내일 새벽 호우특보. …', 질문:'…' }
```

## 🧰 인게임 기획자 패널

퀘스트 진행 중 무대 우측 하단 **[🧰 기획 패널]** 버튼을 누르면, 지금 플레이 중인 퀘스트의
실데이터를 세 가지 탭으로 확인할 수 있습니다.

### 🎬 연출 큐시트
지금 재생 중인 프리셋의 **이름 · 의도 · 큐시트 전문**과, 그 연출이 데이터 지정인지
자동 배정인지를 그대로 보여줍니다.

### 🗂 퀘스트 데이터 (`js/questdata.js` — `QuestTable`)
흩어져 있는 퀘스트 정의를 **선택지 단위 행으로 평탄화한 한 장의 테이블**로 봅니다.

```
QUEST_ID | STEP | CH | 성과 | 스트 | 인내 | TRAITS | CUE_ID | SRC | STAGE | SPEAKER | CHOICE_TEXT | …
chef_realistic_ep1 | 1 | A | +2 | 0 | +1 | #완벽주의+2 | 도입_와이드풀인 | 자동 | 실무 투입 | 친절한 사수 | …
```

- 컬럼 순서는 **키 → 구조 → 수치 → 연출 → 문장**. 좁은 패널에서도 판단에 필요한 값이 먼저 보입니다.
- 헤더에 마우스를 올리면 **스키마 설명**이 뜨고, 현재 플레이 중인 컷은 강조됩니다.
- 상단에 집계(에피소드 수 · 분기 수 · 연출 종류 · **연출 직접지정률** · **성향태그 커버리지**).
- **⬇ CSV 내보내기** — BOM 포함 UTF-8이라 엑셀에서 한글이 깨지지 않습니다. (`quest_<직업>_<모드>.csv`)

### 🩺 데이터 자동 점검 (`QuestDoctor`)
돌려보지 않아도 보이는 결함을 잡아 유지·관리 비용을 줄입니다.

| 점검 | 예시 |
|---|---|
| 빈 칸 | 상황/질문 누락, 선택지 3개 미만 |
| 무의미한 분기 | 모든 선택지의 효과 수치가 동일 |
| 성향 미반영 | 성향 태그(#)가 하나도 없는 컷 |
| 연출 리듬 | 직전 컷과 연출 프리셋이 동일 (단조로움) |
| 긴장 과밀 | 고비 컷 3연속 |
| 마무리감 | 마지막 컷이 결단/마무리 계열 연출이 아님 |

> 실제로 `chef` 퀘스트에서 `ℹ️ EP2·EP3 연출이 연속으로 「당황_흔들림」입니다 → 한쪽에 `연출:`을 지정해 보세요` 를 잡아냅니다.

### 🔀 에피소드 흐름 (`QuestFlow`)
컷을 노드 그래프로 펼쳐 **도입 → 딜레마 → 판정 → 엔딩 분기** 구조를 한눈에 봅니다.
각 노드에 단계 · **톤(평온/승부/고비)** · 출연 NPC · 분기 수 · 연출 프리셋이 붙고,
마지막에 히든/성공/별종/퇴사 엔딩과 각 판정 조건이 이어집니다.

```
[EP1 승부]─▶[EP2 고비]─▶[EP3 고비]─▶[EP4 승부]─▶[EP5 고비]─▶[판정]
                                                              ├ 🏆 히든 심층 엔딩
                                                              ├ 🌟 미쉐린의 예감
                                                              ├ 🍀 창작 요리 몽상가
                                                              └ 🚪 양파 눈물 조퇴자
```

## 🚀 Vercel로 1분 만에 배포하고 공유 링크 만들기

빌드 과정이 없는 정적 사이트라서 아래 명령 두 번이면 끝입니다.

1. 이 프로젝트 폴더에서 터미널을 열고 아래 명령을 실행합니다.
   ```bash
   npx vercel
   ```
   - 처음 실행하면 Vercel 로그인(GitHub/이메일)을 요구합니다. 안내에 따라 로그인하세요.
   - "Set up and deploy?" → `Y`
   - "Which scope?" → 본인 계정 선택
   - "Link to existing project?" → `N`
   - "What's your project's name?" → 원하는 이름 입력 (예: `projectjob`)
   - "In which directory is your code located?" → 그대로 Enter (`./`)
   - 나머지 질문은 기본값(Enter)으로 진행하면 됩니다.
   - 완료되면 `https://프로젝트이름-랜덤값.vercel.app` 형태의 **미리보기 링크**가 바로 출력됩니다.

2. 프로덕션(고정) 링크로 배포하려면:
   ```bash
   npx vercel --prod
   ```
   - `https://프로젝트이름.vercel.app` 형태의 고정 링크가 생성됩니다. 이 링크를 이력서/포트폴리오에 공유하면 됩니다.

### GitHub 연동으로 배포하는 방법 (선택)

1. 이 폴더를 GitHub 저장소에 push 합니다.
2. [vercel.com/new](https://vercel.com/new)에서 해당 저장소를 Import 합니다.
3. Framework Preset은 **Other**(정적 사이트) 그대로 두고 Deploy를 누르면 끝입니다.
   - Build Command / Output Directory는 비워둬도 됩니다(정적 파일이라 빌드가 필요 없음).

## 프로젝트 구조

```
index.html      게임 실행 파일 (Vercel 배포 시 루트 진입점)
js/icons.js     인라인 SVG 아이콘 라이브러리
js/data.js      직업/테마/퀘스트 데이터
js/scenarios.js 확장 직업 시나리오 데이터
js/csv.js       CSV로 직업 대량 등록하는 로더
js/avatar.js    아바타/NPC SVG 렌더러
js/room.js      마이룸 빌더(드래그 배치, 테마, 인벤토리)
js/scene3d.js   3D 무대/잡보드 렌더러 (three.js) — 연출 리깅(rig) 제공
js/direction.js 인게임 연출 시퀀스 시스템 (샷 테이블·연출 프리셋·Director)
js/questdata.js 퀘스트 데이터 테이블(QuestTable)·흐름(QuestFlow)·자동 점검(QuestDoctor)
js/sfx.js       절차적 효과음(Web Audio)
js/app.js       게임 엔진 & UI 렌더링
02_ProjectJOB_발표용_게임기획서.html  발표용 기획서 (배포 대상 아님)
```

모든 저장 데이터는 브라우저 `localStorage`에 보관되며, 외부 API 호출이나 서버가 없어
Vercel 무료 플랜 정적 호스팅만으로 100% 동작합니다.
